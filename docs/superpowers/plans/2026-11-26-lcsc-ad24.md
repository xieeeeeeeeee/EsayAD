# LCSC AD24 Assistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 独立桌面窗口搜索立创料号、厂家型号、关键词，生成配套 AD 库并在 AD24 放置。
**Architecture:** Python/Tk 独立窗口，JLCPCB 目录搜索与 EasyEDA 模型获取分离。复用固定提交的 MIT jlc2ad 转换器，DelphiScript 在 AD 中安装库并发起交互式放置，状态文件区分库生成与实际导入。
**Tech Stack:** Python 3.10+, Tk/ttk, urllib, vendored jlc2ad, DelphiScript, unittest, PyInstaller if available.
**Spec:** ../specs/2026-11-26-lcsc-ad24-design.md (用户已于当前聊天确认)

## Global Constraints
- Windows，AD E:\AD24，版本 24.0.1.36；不改 AD 二进制，不覆盖用户库。
- 不把 C 料号查询冒充关键词搜索；JLCPCB 搜索目录覆盖范围须在 UI 与说明中注明。
- 保留料号、厂家型号、来源链接，符号和封装匹配。
- 未支持图元须阻止或明确警告；库生成与 AD 放置成功分开呈现。
- 测试只使用新建临时文档；没有 UI 实测不得声称 AD 集成完成。

## Review Focus
- 目录有商品但没有 EDA 模型：详情与导出显示缺失，不能生成假模型。
- 不支持图元、复杂焊盘、多单元符号：明确阻止，不能无声截断。
- Unicode、引号、空格路径：参数完整保留，脚本注入不可执行。
- 超时、服务返回 HTML、损坏缓存：清楚报错，不保存为成功结果。
- 用户取消放置、没有活动原理图：状态不能报告已放置；现有设计保持不变。

### Task 1: Data and library export
**Files:** vendor/jlc2ad/*, assistant/catalog.py, assistant/exporter.py, tests/test_data.py, tests/fixtures/*
**Interfaces:** Catalog.search(query: str, page: int=1) -> SearchPage; Catalog.component(lcsc: str, refresh: bool=False) -> dict; Exporter.export(lcsc: str, data: dict) -> ExportResult containing library paths, symbol name, footprint name, warnings.
- [ ] Write tests for result mapping, precise ID validation, malformed server response, cache repair and no-model errors; run and observe failures.
- [ ] Vendor MIT converter pinned to a commit, preserving license and binary templates. Implement clients with timeouts, response checking and atomic success-only cache.
- [ ] Implement conversion adapter: reject unsupported shapes, export both libraries in isolated version directories, preserve source data, metadata and pin/pad verification report.
- [ ] Run unittest and real C25804 resistor, C14663 capacitor and C7593 IC exports; inspect libraries using an independent OLE reader. Commit working task.

### Task 2: AD bridge
**Files:** assistant/bridge.py, ad/Bridge.pas, ad/Bridge.PrjScr, tests/test_bridge.py
**Interfaces:** Bridge.prepare(export: ExportResult) -> script project path; Bridge.launch(project: Path, place: bool=True) -> launch result; receipts contain generated/opened/placement_started, never fabricated placement completion.
- [ ] Write tests for safe Pascal quoting, request identity, paths outside output root, and distinction of export and import state; run RED.
- [ ] Use AD documented RunScript process with a generated script project: open libraries, install them via IntegratedLibraryManager, restore target schematic and issue placement only if schematic is active. Use a separate AD launcher script to start the assistant.
- [ ] Validate actual AD24 interfaces in installed assemblies/examples; test in temporary documents through UI, resolve any API mismatches. Run tests and commit.

### Task 3: Independent search window and delivery
**Files:** assistant/app.py, assistant/__main__.py, launch.pyw, Start.cmd, README.md, tests/test_workflow.py, scripts/smoke.py
**Interfaces:** UI uses Catalog, Exporter and Bridge; worker queue sends progress/results to Tk main thread. Output defaults project-local user-writable data/.
- [ ] Write workflow tests for stale selection on new search and request failure keeping export status distinct; run RED.
- [ ] Build Chinese UI with search field, paged result table, selected details, symbol/footprint preview, import button, log and output folder action. Background I/O never blocks UI; keyboard search and clear state messages.
- [ ] Add Chinese launch/install/AD menu binding instructions, sources, license and known conversion/search limits; package if dependencies permit.
- [ ] Run unit suite, real query tests for C25804, NE555DR and capacitor keyword, UI smoke, AD library and placement smoke. Capture evidence with honest unverified items. Commit and fresh reviewer pass.
